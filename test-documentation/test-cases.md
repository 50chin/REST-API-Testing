# Тест-кейсы: Users API

## TC-01. Получение пользователя по ID

* **Метод:** GET
* **URL:**  {{baseUrl}}/users/1
* **Предусловие:** API доступен
* **Шаги:**
  1. Отправить GET-запрос
  2. Проверить статус ответа
  3. Проверить поля ответа
* **Ожидаемый результат:**
  * Статус 200 OK.
  * Ответ содержит id, name, email, username
  * Значение id равно 1

## TC-02. Получение списка пользователей

* **Метод:** GET
* **URL:** {{baseUrl}}/users
* **Шаги:**
  1. Отправить GET-запрос
  2. Проверить статус и структуру ответа
* **Ожидаемый результат:**
  * Статус 200 OK
  * Ответ является массивом
  * Массив не пустой
  * У каждого пользователя есть id и email

## TC-03. Запрос несуществующего пользователя

* **Метод:** GET
* **URL:**  {{baseUrl}}/users/999
* **Шаги:**
  1. Отправить GET-запрос
  2. Проверить статус и тело ответа
* **Ожидаемый результат:**
  * Статус 404 Not Found
  * Пустой JSON-объект {}
