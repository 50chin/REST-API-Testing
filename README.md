# Postman API Testing

## Описание проекта

Учебный проект по тестированию REST API с использованием Postman и JSONPlaceholder

## Инструменты

* Postman
* REST API
* JavaScript для автоматических проверок
* GitHub для хранения проекта

## Протестированные ресурсы

* **Users** — получение пользователя, списка пользователей и проверка негативных сценариев
* **Posts** — получение публикации и списка публикаций
* **Comments** — получение комментария и комментариев к публикации

## Типы проверок

* HTTP-статус ответа
* Формат JSON
* Структура и обязательные поля
* Корректность идентификаторов
* Проверка массивов и их содержимого

## Запуск тестов

1. Импортировать коллекцию Postman
2. Проверить переменную baseUrl
3. Запустить коллекцию через Collection Runner
4. Изучить результаты автоматических проверок
